## 🚨 Códigos de Erro e Luzes de Alerta

### ⚠️ Code Affiché : 'SHUT'
- **Causa comum:** Código Code Affiché : 'SHUT': verificação de rotina do sensor
- **Solução sem ferramentas:** Desligue o aparelho por 30 segundos, limpe os contactos e reinicie.

### ⚠️ Message : 'E01' ou 'E02'
- **Causa comum:** Código Message : 'E01' ou 'E02': verificação de rotina do sensor
- **Solução sem ferramentas:** Desligue o aparelho por 30 segundos, limpe os contactos e reinicie.
