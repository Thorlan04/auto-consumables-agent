## 🚨 エラーコード・警告ランプの解除

### ⚠️ Code Affiché : 'SHUT'
- **主な原因:** 警告コード Code Affiché : 'SHUT': センサーの日常点検が必要です
- **工具不要の解除手順:** 主電源を30秒間切り、センサー接点を拭き取ってから再起動してください。

### ⚠️ Message : 'E01' ou 'E02'
- **主な原因:** 警告コード Message : 'E01' ou 'E02': センサーの日常点検が必要です
- **工具不要の解除手順:** 主電源を30秒間切り、センサー接点を拭き取ってから再起動してください。

### ⚠️ Fumée Blanche en Cours de Cuisson
- **主な原因:** 警告コード Fumée Blanche en Cours de Cuisson: センサーの日常点検が必要です
- **工具不要の解除手順:** 主電源を30秒間切り、センサー接点を拭き取ってから再起動してください。
