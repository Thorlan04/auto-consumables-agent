## 🚨 Waarschuwingslampjes & Reguliere Foutcodes

### ⚠️ Code Affiché : 'SHUT'
- **Veelvoorkomende oorzaak:** Storingscode Code Affiché : 'SHUT': reguliere sensorcontrole vereist
- **Oplossing zonder gereedschap:** Schakel het apparaat 30 seconden uit, veeg externe sensoren schoon en herstart.

### ⚠️ Message : 'E01' ou 'E02'
- **Veelvoorkomende oorzaak:** Storingscode Message : 'E01' ou 'E02': reguliere sensorcontrole vereist
- **Oplossing zonder gereedschap:** Schakel het apparaat 30 seconden uit, veeg externe sensoren schoon en herstart.
